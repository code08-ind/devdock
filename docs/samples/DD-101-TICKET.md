## Summary

Checkout total rounds wrong for 3-decimal currencies

## Description

Orders in `KWD` and `BHD` show a total off by 0.001.

##### Steps to reproduce

1. Switch the demo store to Kuwaiti dinar
2. Add two items at 1.005
3. Open checkout

##### Expected

Total is **2.010**, not 2.009.

```ts
const total = items.reduce((s, i) => s + i.price, 0) // float sum
```

- Totals use minor units for every currency
- A unit test covers 0-, 2- and 3-decimal currencies
